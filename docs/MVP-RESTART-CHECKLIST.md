## 限制与安全停点

本增量只支持保留原 `/tmp` 目录及端点身份的干净桌面重启；系统重启、`/tmp` 清理或 crash 遗留 socket 可能导致恢复失败。没有 crash recovery/reset/revoke-all；不能靠删除未知 socket/记录或重新部署“修复”。记录不确定时停止并保存脱敏证据，请求单独授权处理。旧版本 process-only artifact 永不自动认领。legacy 不是 managed auth/ack 或完整 ACL 安全。
