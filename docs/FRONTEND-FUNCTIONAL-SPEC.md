# Agent Pet 前端功能说明与原型设计交接

> 用途：供设计 Agent 重新设计完整前端原型。本文描述用户能做什么、状态如何变化、哪些限制不能被设计抹掉，不要求沿用现有布局。
>
> 代码基线：`9bdeb3ceaaf1d882a11904a7a4fa07239e61b36a`。依据当前正式入口、组件、共享数据和产品契约整理；不是全功能运行验收报告。旧截图和 #20 早期方案不代表此基线。
>
> **这是给设计者的功能文档，不是要显示在产品里的说明书。不要把本文段落变成页面副标题、提示卡或折叠帮助。**

## 1. 设计任务与范围

Agent Pet 是本机 macOS 桌面陪伴应用：被动观察用户已安装的 Agent，让在线 Agent 对应的宠物以动作和会话气泡表达状态。它不是 Agent 启动器、聊天客户端、任务调度器或技术运维控制台。

本次原型应覆盖：

1. 管理窗口：**首页、宠物、连接、设置**四个功能域。
2. 桌面悬浮宠物：拖动、缩放、会话气泡和快捷操作。
3. 应用外壳：菜单栏/Dock 恢复入口、窗口生命周期、原生选择与授权对话框。
4. 各入口的空态、正常状态、进行中、失败、取消和受限状态。

可以重做视觉风格、信息层级、导航形式、控件位置、主次动作、弹窗与抽屉的组织。四个功能域不要求继续使用底部四个标签，但它们的功能必须可找到。

不默认扩展业务范围。不添加账号登录、云同步、宠物商城、聊天框、发送任务、审批 Agent、自动更新、远程模型下载、任务进度百分比或使用量仪表盘。

### 本文的三种标记

- **现状**：代码中已有的入口或行为，不等于所有环境都验收通过。
- **约束**：新原型必须保留的业务语义、权限或数据边界。
- **设计空间**：可以改善表达，但不能未经确认改变底层能力。

## 2. 用户与核心目标

面向使用 pi、Claude Code、Codex CLI 的本机用户，包括不了解配置文件和扩展机制的用户。

| 用户目标 | 产品应帮助用户完成 | 不应要求用户先理解 |
| --- | --- | --- |
| 让 Agent 有一只桌宠 | 找到安装、明确授权、建立连接、选择宠物 | 进程身份、观察协议、私有运行目录 |
| 知道 Agent 是否有活动 | 看到可信的在线状态、动作或气泡 | 各 Provider 事件枚举 |
| 换个宠物 | 选形象、预览动作、绑定指定连接 | GLB 内部动画命名 |
| 少打扰、少耗电 | 控制显隐、提醒、大小、渲染和后台运行 | 图形引擎参数实现 |
| 暂时不用或彻底移除 | 区分隐藏、暂停观察、解绑、删除资产、移除连接 | 文件所有权实现细节 |
| 连接有问题 | 知道当前发生了什么，以及能采取什么动作 | 错误码、内部状态机或堆栈 |

## 3. 对象与关系：设计前必须分清

| 对象 | 含义 | 关键关系 |
| --- | --- | --- |
| Agent 类型 / Provider | pi、Claude Code、Codex 等接入类型 | 同一类型可以有多条连接 |
| 程序安装 | 本机找到的某个程序及版本、安装方式 | 找到程序不代表支持，也不代表已经连接 |
| 连接配置，界面简称“连接” | 用户命名的一组 Agent 类型、配置位置和连接设置 | 有独立身份；不能按名称或 Agent 类型合并 |
| 会话 Session | 连接下某次实际会话 | 一个连接可以有多个会话；每个会话独立通知 |
| 宠物资产 | 内置或导入的模型、动作映射和可选头像 | 收藏中的资源，不等于已出现在桌面 |
| 宠物绑定 | 某条连接选用哪个资产及绑定时的宠物名 | 一条连接最多一个绑定；同一资产可供多条连接使用 |
| 可见宠物实例 | 在线且已绑定的连接投影 | 同一资产可同时出现多只，每只属于不同连接 |
| 偏好 | 应用级显示、提醒、渲染和入口设置 | 不等于连接配置；恢复偏好不删除连接和资产 |

必须保持的区别：

- 选中收藏资产 ≠ 绑定连接。
- 保存连接记录 ≠ 已部署观察设置 ≠ Agent 已在线 ≠ Agent 正在工作。
- 位置可用 ≠ 连接健康；连接健康 ≠ 会话任务成功。
- 暂停连接 = 停止 Agent Pet 观察，不是暂停 Agent 工作。
- 解绑 = 不让此连接显示这只宠物，不停止观察，不删除资产。
- 隐藏宠物 = 显示偏好，不断开连接，也不是退出应用。
- 工具调用成功 ≠ 整轮任务完成。

## 4. 全局行为与应用外壳

### 4.1 窗口

- 当前管理窗口初始为 **900×680**，原生最小尺寸 **400×400**。原型应覆盖默认尺寸、宽窗口和窄矮窗口；不要只做桌面大图。
- macOS 使用原生窗口按钮；其他环境有 HTML 最小化、最大化/还原、关闭按钮回退。这不代表其他系统已正式支持。
- 点击应用标识回首页。当前页面切换不另开管理窗口。
- 关闭管理窗口与退出应用不同：开启后台运行时只隐藏管理窗口；关闭后台运行时会退出整个应用。
- 明确“退出 Agent Pet”结束本应用，不结束 Agent。
- 状态读取失败提供重新读取；保存失败不能假装已成功。无法读取导入模型时可显示内置模型并告知异常，场景加载失败提供重新加载。
- 管理页与桌面消费同一业务事实，不允许一个显示离线、另一个用假数据继续工作。

### 4.2 系统入口

| 入口 | 当前动作 |
| --- | --- |
| 菜单栏图标点击 | 打开或恢复管理窗口 |
| 菜单栏菜单 / 应用菜单 | 打开管理窗口、隐藏/显示宠物、退出 Agent Pet |
| Dock | 提供应用恢复入口；可由偏好控制是否显示 |
| 应用菜单的 View/Edit | 当前有系统编辑、重载、开发工具、全屏等菜单能力；不应在主界面复制一排工程按钮 |

至少保留菜单栏或 Dock 中一个可用入口。失败时不能把用户锁在没有恢复入口的后台应用里。

## 5. 首页：观察陪伴，不负责配置

### 功能

- 展示所有**在线且显式绑定**的连接宠物，不按 Provider 或资产去重。
- 默认是宠物全景，不给每只宠物常驻一套技术标签。
- 点击一只模型，或使用对应 HTML 键盘入口，进入聚焦状态。
- 聚焦时显示：Agent 类型、宠物名、当前状态、连接名称。
- 点击空白、按 Escape 或返回全景，退出聚焦。
- 被聚焦的连接离线或解绑后，清除失效聚焦。
- 连接操作属于连接功能域，不在首页重做连接表单。

### 状态

| 场景 | 必须表达的事实 |
| --- | --- |
| 无在线且绑定的连接 | 没有可展示的在线宠物；不是加载失败 |
| 已连接但尚未绑定 | 不生成默认桌宠；需要能发现去选择/绑定宠物的路径 |
| 一只/多只在线宠物 | 各自对应独立连接，多个同类型 Agent 也应可区分 |
| 聚焦一只 | 显示身份与可信状态；可退回全景 |
| 模型加载中/失败 | 不把加载失败当 Agent 断线；保留恢复入口 |
| Claude 旧陪伴模式 | 可以在线陪伴，但任务状态不可用；不能伪造工作/完成 |

**现状边界**：首页不是会话列表或通知中心，没有完整聊天记录、会话管理、启动 Agent 或任务操作入口。当前空态很简短；新原型可改善下一步的可发现性，不必追加说明段落。

## 6. 宠物：收藏、外观、动作和绑定

### 6.1 当前选中宠物

- 居中预览当前资产；首页与宠物页共用场景基础设施，但承担不同任务。
- 可以修改展示用宠物名称：去除首尾空白，非空，最多 40 字；保存、取消、Escape 返回。
- 上一只/下一只轮换收藏，单资产时禁用；可直接打开收藏选择。
- 当前选中资产保存在偏好中。普通选择不需要重复成功提示。

**命名现状需特别注意**：当前 `petName` 是应用偏好中的一个名称，不是每个资产各自的可编辑名称。导入资产的收藏标题主要来自包 ID；绑定会保存当时的宠物名。编辑预览名称不会自动同步已有绑定名称。原型不能把“每只收藏宠物独立重命名、全局同步”画成已有能力；如要改善，单列为需要产品/数据结构确认的提案。

### 6.2 收藏

| 操作 | 行为与边界 |
| --- | --- |
| 打开收藏 | 展示内置/导入宠物、头像或占位图、名称、当前选中态 |
| 搜索 | 当前按显示使用的名称/包 ID 匹配；没有结果时显示空态，不是假装收藏为空 |
| 选择宠物 | 更新预览和选中偏好，不自动给连接换宠物 |
| 添加宠物 | 进入本地文件夹导入流程 |
| 删除导入宠物 | 要求确认；有连接绑定时拒绝并要求先解绑；内置宠物不可删除 |
| 删除失败 | 保留错误反馈，不能只让卡片消失而假装成功 |

### 6.3 导入流程

```text
打开导入 → 选择本地文件夹 → 读取并校验
  ├─ 取消选择：回到导入入口
  ├─ 无效/重复/超限：显示原因，可重新选择
  └─ 有效：展示包 ID、模型大小、许可
       ├─ 重新选择：释放旧预览
       ├─ 取消：释放预览，不安装
       └─ 确认导入 → 导入中 → 加入收藏并选中
```

- 选择的是包含 `pet.json` 和 `pet.glb` 的**宠物包文件夹**，不是任意裸 GLB 拖入即可成功。
- 当前导入确认展示元信息，不是独立的实时 3D 导入预览；导入后在宠物页看模型。
- 只支持受约束、自包含的 GLB；不支持 VRM、FBX、远程下载和外部纹理依赖。格式/资源超限会拒绝。
- 动画全部可选，无动画的有效模型应能静态展示，不得强迫补齐动作。
- 预览来自私有快照；文件选择不是安装确认。确认中不得把关闭弹窗当成撤销已发生的安装。
- 导入不会自动绑定、替换已有连接的宠物，也不修改原始素材文件夹。
- 需要表现：读取中、有效预览、取消、重新选择、安装中、重复、容量达到上限、格式失败、读取失败、预览失效、安装结果不确定。

### 6.4 绑定连接

- 当前资产显示使用它的连接标签；标签必须能区分两个同类型 Agent。
- 点击添加绑定入口，列出已保存连接，包含连接名称、Provider 和使用情况。
- 点击未绑定当前资产的连接，为其选择当前资产；它原来用其他资产时，此操作会替换绑定。
- 再次点击已使用当前资产的连接，解除绑定。标签关闭按钮也是解绑，不是移除连接。
- 离线连接也可以预先绑定；仅在连接在线后出现桌宠。
- 没有连接时显示空态。修改失败保留原状态，不伪造成功。

### 6.5 动作试播

- 只列出当前资产实际具备的可用动作；可搜索、选择和重复播放当前动作。
- 动作面板是非模态选择面板；Escape、切页可收起，模型保持可见。
- 没有可用动作时静态展示，试播控件不可用。
- 试播只作用于管理页预览，不向 Agent 发消息，也不伪造会话事件。
- 模型具备某个动画，不代表每种 Agent 都能自动触发它。详细能力见第 11 节。

## 7. 连接：从发现到撤回的完整流程

### 7.1 列表与详情

当前是列表/详情结构，窄窗口可从详情返回列表。原型可换形式，但必须支持：

- 多条连接，同 Provider、同名连接也不误合并；当前上限 64 条。
- 核心身份：连接名称、Provider、单一主要连接状态、配置位置。
- 配置位置可以省略显示，但在定位/授权需要时能够查看完整目标。
- 原位重命名：自动选中原名称，非空、最多 40 字，保存/取消，失败保持可处理状态。
- 添加方式：自动扫描为优先入口，手动添加为补充。
- 列表加载中、无连接、选中详情、读取失败、保存中、连接已被移除等情况。

### 7.2 自动扫描

```text
自动扫描 → 必要的原生扫描授权 → 正在查找安装
  ├─ 用户取消 → 返回连接列表
  ├─ 无安装 / 部分扫描受限 / 扫描失败 → 重试或手动添加
  └─ 找到候选 → 选择安装/查看已有连接
       → 明确目标，读取并预览 → 检查中
       → 展示精确连接变更 → 取消 或 确认连接
```

- 扫描不自动安装、不执行候选程序、不启动 Agent。
- 识别 pi、Claude Code、Codex；只对已验证安装提供可执行接入动作，不能把“发现路径”画成绿色“兼容”。
- 多安装时允许区分安装方式、版本和位置；技术明细不是默认页面必须铺开的内容。
- 已有连接优先查看详情；尚未配置的 Codex 记录仍可继续读取与预览，不能被“已添加”堵死。
- 可以取消扫描、重新扫描，部分 Provider 扫描失败不等于所有结果无效。
- Codex 自定义目标继续使用原连接位置，不能静默回退到默认配置。
- 安装/目标发生变化，要求重新扫描或重新预览；不得确认过期计划。
- 取消预览不等于删除保存的连接记录；不要承诺每次取消后列表一定为空。

### 7.3 手动添加 / 更换位置

当前三个阶段：

| 阶段 | 输入/操作 | 继续条件 |
| --- | --- | --- |
| 选择配置文件夹 | 原生目录选择器，显示选定路径 | 已选择有效路径 |
| 选择 Agent | 选择 Provider；pi 可检查/重新检查位置 | 已授权、有 Provider、无相同 Provider+位置的重复记录；pi 已完成一次检查 |
| 命名连接 | 名称，默认“个人配置” | 非空且不超过 40 字 |

- 上一步保留已输入内容；关闭/取消返回原入口。
- **当前没有路径粘贴输入框**。后端仍有路径读取授权能力，不等于前端已经开放此入口。
- pi 检查发现问题可展示发现项；保存记录不代表允许部署，真正写入仍由后续预览限制。
- 手动选择包含 pi、Claude Code、Codex、OpenCode、Gemini CLI、Cursor；后三种当前只可记录元数据，不能实际接入。
- 更换位置复用流程，Provider 固定。已经部署/配置、存在不确定状态及旧兼容记录不能任意换目录，应先完成撤回再添加。
- 不能把更换位置设计成把旧扩展自动搬到新目录。

### 7.4 连接状态与操作

下面是语义分类，不要求复制这些词作为所有 Provider 的统一文案。

| 状态 | 用户应理解 | 可能动作 |
| --- | --- | --- |
| 还未连接 | 记录存在，尚未完成设置 | 设置连接 |
| 正在检查/保存 | 操作未结束 | 检查阶段可取消；写入期间防重复确认 |
| 等待 Agent / 等待启动 / 等待活动 | 观察已准备，但没有足以证明在线的事实 | Provider 对应的下一步，不假装已在线 |
| 已连接 / 观察已连接 | 已观察到可信在线事实 | 查看；必要时暂停观察 |
| 已暂停 | 用户暂停了观察，Agent 可继续运行 | 继续连接 |
| 等待重新连接 / 已断开 | 保存材料还在，但尚未恢复有效连接 | 重新连接，或等待受支持的重连 |
| 连接需要处理 | 安全检查、保存或运行材料出了问题 | 按具体原因检查/重试/重新扫描；不能无条件“修复全部” |
| 暂不支持 | 类型、版本、安装方式或平台尚未支持 | 返回/查看限制；不允许连接 |

动作必须由实际可用能力控制，不仅凭状态文字猜测。位置检查结果、连接健康、Session 业务状态不能合并为一个“成功/失败”灯。

### 7.5 Provider 差异

| 项目 | pi | Claude Code | Codex CLI |
| --- | --- | --- | --- |
| 当前有界支持 | pi 0.85.1 TUI | macOS npm 2.1.301 的已验证布局 | standalone 0.163.0 的已验证布局 |
| 常见配置位置 | `~/.pi/agent`，实际位置可能由环境指定 | `~/.claude` 或项目 `.claude` | 实际 CODEX_HOME，通常 `~/.codex`；不是项目 `.codex` |
| 设置变更 | 新建 `extensions/agent-pet.ts` 及必要目录 | 在目标 `settings.json` 中追加本应用 hooks，并保存私有连接材料 | 在目标 `hooks.json` 中追加本应用通知，并保存私有连接材料 |
| 预览重点 | 精确目录、扩展文件、创建是否被阻止 | 目标设置文件、新建/更新、相关文件、是否可应用 | 精确目标、追加数量、可展开事件及脱敏追加结构 |
| 用户后续操作 | 自行启动 pi；已运行时在安全空闲时 `/reload` | 新设置/升级后需新 Claude 会话；不会接管未向新观察器报到的旧进程 | 用户在 Codex `/hooks` 中独立审核，再产生实际活动 |
| 恢复差异 | 保存连接后存在显式重新连接路径 | 未暂停的正常模式可校验后恢复；显式暂停保持暂停 | 校验已有材料恢复，不能重复追加 hooks |
| 特有分支 | 同名文件、入口/忽略规则等可能阻止部署 | 旧陪伴模式、启用任务反馈升级、旧启动命令复制分支 | 安装扫描证据失效需重新扫描；不提供任意程序文件选择 |

**不能统一掉的边界：**

- Agent Pet 不自动启动、重载、信任或审批这些 Agent。连接确认是授权本应用的设置变更，不是同意它代用户执行任务。
- 部署成功不保证扩展已经加载，更不保证立即出现宠物。
- 新建 Codex 空会话不保证立刻产生启动反馈；不能用等待几秒就强行显示在线。
- Claude 的旧陪伴模式只有存在性观察；任务反馈升级必须显式预览与确认。旧终端启动命令分支仍需可呈现，但不是新用户的主流程。
- Codex 展示的是脱敏结构，不是可复制执行的完整命令。原型不能添加“执行此 JSON/命令”按钮；不要暴露实际私有命令或用户已有 hooks。
- 当前版本限制是事实边界，不意味着主页面必须常驻一整段版本说明。

### 7.6 更多操作与移除

| 操作 | 实际效果 | 不应暗示 |
| --- | --- | --- |
| 检查位置 | 检查 pi 配置位置并刷新结果 | 修复或改写配置 |
| 暂停连接 | 停止本应用观察，保存相应暂停状态 | 暂停/终止 Agent 任务 |
| 继续/重新连接 | 校验并恢复观察 | 自动启动 Agent，或覆盖损坏文件 |
| 更换位置 | 在允许时修改目标元数据 | 自动搬迁已部署文件 |
| 移除连接 | 确认后撤回可证明属于本应用且未改动的连接内容，并移除记录 | 删除 Agent 程序、用户原配置、所有残留 |

移除确认必须能辨认是哪条连接、哪处目标。pi 可能删除本应用创建且未改动的扩展；Claude/Codex 选择性撤回自有 hooks，可能保留运行材料。修改过、来源不明或不能安全清理的材料必须保留；移除不完整时不能把记录隐藏成成功。

已加载的 pi 扩展不会因删文件立即卸载；必要时仍需用户 `/reload` 或正常退出。相关后果应在用户要做决定的时机表达，不必整段常驻详情。

## 8. 设置：全部现有选项

现有分类是渲染、软件、宠物、提醒、关于。保存为即时操作，没有统一“保存设置”页脚。进行中防重复提交，失败保留反馈。分类导航和正文需在窄矮窗口保持可达。

### 8.1 渲染

| 项目 | 可选值 | 默认/含义 |
| --- | --- | --- |
| 画质档位 | 省电：30 FPS / 75%；均衡：60 / 100%；清晰：60 / 150% | 默认均衡 |
| 帧率上限 | 30、60、120 FPS | 上限，不是实测帧率承诺 |
| 渲染清晰度 | 75%、100%、150% | 渲染分辨率比例，不改变宠物/窗口尺寸 |
| 隐藏时暂停渲染 | 开/关 | 默认开 |

精细调整可以折叠；非预设组合当前不会选中任何预设卡，原型可明确呈现“自定义”，但不能新增不支持的值。

### 8.2 软件

| 项目 | 默认 | 依赖/效果 |
| --- | --- | --- |
| 菜单栏图标 | 开 | 与 Dock 至少留一个；不能同时关闭 |
| Dock 图标 | 开 | 系统入口建立失败时保留替代入口 |
| 登录时启动 | 默认不启用 | 需要用户显式操作系统能力；不支持环境中禁用 |
| 启动时打开管理窗口 | 关 | 影响启动时是否主动打开管理窗口 |
| 关闭窗口后继续运行 | 开 | 关闭时隐藏管理窗口；关时关闭窗口会退出应用 |

不支持登录启动时应能理解控件为什么不可用；这是设计需要解决的反馈，不要求添加常驻说明书。

### 8.3 宠物

| 项目 | 当前控件/默认 | 说明 |
| --- | --- | --- |
| 宠物大小 | 当前设置滑条 60%–140%，5% 步进；100%=140 | 后端允许 80–600 CSS 像素，桌面缩放走同一偏好；两者范围并不相同，不能混写成滑条支持全部范围 |
| 显示桌面宠物 | 默认开 | 全局显隐，不改变在线事实或绑定 |

| 显示提醒气泡 | 默认开 | 全局气泡开关 |
| 减少动画 | 默认关 | 保留必要状态表达，减少动画；同时考虑系统减少动态效果偏好 |

### 8.4 提醒

- 任务完成、任务出错分别开关，默认均开启。
- 只控制该类气泡的显示，不是 Agent 消息订阅或业务状态开关。
- 气泡总开关关闭时，在提醒页显示关闭状态及开启入口；保留用户各项偏好。
- 当前没有音量、提醒声音、系统通知中心、勿扰时段或自定义通知规则。

### 8.5 恢复默认与关于

- 恢复默认要确认，支持取消、执行中、失败；不删除连接、收藏、绑定、宠物名称。
- 会恢复显示/渲染/提醒等偏好，包括把当前预览选择恢复为内置宠物；已有连接绑定不因此改绑。
- 在系统支持时还会关闭登录启动。部分步骤失败不能宣称全部恢复成功。
- 当前关于页显示产品名、`0.1.0` 版本文字和 GitHub 项目链接；没有检查更新、账号或订阅。

## 9. 桌面悬浮宠物与会话气泡

### 9.1 出现与消失

- 每条在线且已绑定连接对应独立宠物；同 Provider 可多只，同资产可多只。
- 离线或解绑立即移除实例，没有默认离线宠物占位。
- “显示桌面宠物”关闭时不显示桌宠，但不停止连接观察。
- 管理页收藏预览不受“必须在线”限制，不能把它与桌面可见条件混为一谈。

### 9.2 移动与快捷操作

- 拖拽宠物移动所属桌面窗口，气泡跟随；不是分别拖动每个气泡。位置属于当前实例，现状不承诺离线重建或重启后记住位置。
- 悬停/聚焦可露出紧凑工具栏：本宠物气泡显隐、调整大小。
- 缩放支持拖动及方向键。桌面缩放修改全局大小偏好，不是独立保存每只宠物的尺寸。
- 工具栏的气泡隐藏是当前实例的临时状态；设置中的气泡开关是全局持久偏好。关闭全局气泡后，局部开关不能绕过它。
- 宠物和工具栏之间保持可达区域，不因鼠标经过间隙就失去操作；远处透明区域穿透，不应遮住桌面。
- 普通桌宠不常驻名称牌，不抢前台应用焦点。拖拽/缩放结束、失焦或隐藏要释放操作状态。

### 9.3 气泡

| 状态 | 展示 | 点击结果 |
| --- | --- | --- |
| 正在工作 | 会话名 + 工作状态 | 尝试打开原会话；工作气泡保留 |
| 完成未读 | 会话名 + 完成状态 | 确认已读、移除气泡，并尝试打开原会话 |
| 错误未读 | 会话名 + 错误状态 | 确认已读、移除气泡，并尝试打开原会话 |

- 每个 Session 最多一个气泡，多 Session 独立，不做跨会话合并或去重。
- 多个气泡紧凑堆叠，悬停或键盘聚焦展开；布局可在宠物上方/下方适配空间。
- 名称来自 Agent 原生名称、项目名称或生成名称，不能拿对话正文冒充标题。
- 不显示 prompt、回答、工具参数/输出、transcript、凭据、token 或精确进度。
- 打开原会话可能成功、不支持、找不到或权限不足；失败应反馈，但不恢复已确认的结果气泡。
- pi 当前不支持打开原会话；不能偷偷新开终端/启动 pi 冒充跳转成功。其他 Provider 也不能在无依据时承诺跳转。
- 未读不要求跨应用重启恢复。没有 idle 气泡，断线也不能伪造成任务完成或错误。

## 10. 原生与跨层对话框清单

这些不能因原型只画网页而遗漏。浏览器原型可以用明确标注的模拟，但不应让模拟执行真实写入。

| 场景 | 系统/应用表面 | 用户要决定什么 |
| --- | --- | --- |
| 扫描 Claude/Codex 安装 | 原生授权框 | 是否允许检查指定安装范围 |
| 选择配置文件夹 | 原生目录选择器 | 哪个目录是目标 |
| 路径读取授权能力 | 原生授权框；当前手动流程主要用选择器 | 是否读取这个明确目标；不是写入许可 |
| 自动发现后的读取预览 | 应用弹窗 | 对候选配置进行检查并生成变更预览 |
| Claude 手动程序选择分支 | 原生文件选择器 | 哪个受支持的 Claude 安装；Codex 不沿用此设计 |
| 连接写入预览 | Provider 对应应用弹窗 | 是否应用这次精确变更 |
| 移除连接 | 应用确认弹窗 | 是否撤回这条连接，接受对应后果 |
| 绑定宠物 | 应用选择弹窗 | 哪些连接使用当前资产 |
| 导入包选择 | 原生目录选择器 | 哪份本地宠物包 |
| 确认导入 | 应用弹窗 | 是否将已预览内容加入收藏 |
| 删除导入资产 | 当前使用确认对话框 | 是否删除该收藏；有绑定时必须先解绑 |
| 恢复默认 | 应用确认弹窗 | 恢复偏好，不删除用户连接和收藏 |
| 关闭窗口/退出 | 窗口与系统菜单 | 隐藏管理窗口，还是结束本应用 |

## 11. 动画能力：完整目录不等于全面支持

原型可以设计状态感，但不能把动画目录变成一排用户无需操作的状态开关。

### 11.1 当前动作目录

- 持续/基线：空闲、工作、思考、输出回答、读取文件、修改文件、搜索、执行命令、压缩上下文、等待输入、重试。
- 结果/事件：任务完成、任务错误、工具失败、输出达到限制、取消、连接。
- 本地交互：悬停、首页选中、桌面拖动。
- 其他目录项：attention 用作回退；disconnected 可手动试播，但离线即移除，没有自动断线动画载体。
- 没有独立 sleeping/休眠业务状态。隐藏停帧不是睡觉。

### 11.2 Provider 能力差异

| 能力 | pi | Claude 任务反馈模式 | Codex |
| --- | --- | --- | --- |
| 持续工作、思考、输出 | 有对应可靠事实时展示 | 不从 submit/前置 hook 推断持续工作 | 同 Claude |
| 读/写/搜索/命令 | 对应工具执行区间 | 已知工具结果后的短反馈 | Bash / apply_patch 结果后的短反馈，不从正文猜读取/搜索 |
| 整轮完成未读 | 有终态且确认空闲时 | Stop 不足以证明完成 | Stop/工具返回不足以证明完成 |
| 整轮错误未读 | 支持的终态错误 | 已知当前请求的 StopFailure | 当前无统一可靠来源，不承诺 |
| 等待输入/压缩 | 有明确配对事实时 | 不凭单个前置事件推断 | 不凭审批事件推断 |
| 重试 | 当前可靠来源不足 | 未证实 | 未证实 |

动画只有在**Provider 有可信事实、产品有对应表达、资产有可用动作**时才能按该动作呈现；缺失可回退至工作/空闲或静态，不应报“宠物不可用”。

多会话气泡独立，但一只连接宠物同一时刻只有一个选中的视觉状态。快速事件可能相互覆盖，不承诺排队播完。拖动优先于本地悬停/选择反馈，结束后恢复最新业务状态。连接动作不是每次页面打开都重播。

`in / loop / out` 持续状态分阶段播放是已确认但尚未实施的后续设计，不能写成当前原型必须依赖的运行能力。

## 12. 空态、错误和忙碌状态的设计要求

| 类别 | 原型至少要表达的分支 | 不能做的事 |
| --- | --- | --- |
| 初始状态 | 无连接、无在线宠物、只有内置资产、无绑定 | 先放几只“演示在线宠物”冒充真实状态 |
| 查找状态 | 扫描中、无结果、部分结果、受限、取消 | 把部分失败变成全页不可用 |
| 配置状态 | 未检查、可用、检查有问题、不支持、重复、数量上限 | 用“添加成功”承诺已经在线 |
| 写入状态 | 准备中、可确认、被阻止、过期、保存中、结果不确定 | 不确定时显示成功或自动重试写入 |
| 维护状态 | 已暂停、恢复失败、文件已修改、移除不完整 | 自动删未知文件或隐藏未完成记录 |
| 资产状态 | 搜索无结果、读取/格式失败、重复、加载失败、被绑定不能删 | 错误模型替换成正常模型却不告知 |
| 偏好状态 | 保存中、保存失败、依赖禁用、系统不支持、部分恢复失败 | 只凭开关动画认定保存成功 |
| 通知状态 | 多会话、隐藏、打开原窗口失败、能力不支持 | 通过对话正文补出未知状态 |

错误信息应让用户知道问题及下一步。确有文件保留/结果不确定时保留这个事实；不用堆栈、状态码或大段保护机制代替解释。正常态无需重复宣布“这是安全的”“这不会执行任务”。

## 13. 授权、隐私与可撤回约束

这些是流程约束，不规定必须使用长文案。

1. **先识别目标，再请求许可。** 用户必须分清在处理哪条连接、哪个配置目录。
2. **读取与写入分开。** 扫描/选择/读取同意不能变成部署授权。
3. **预览对应一次具体变更。** 明确将新增、修改或撤回什么；目标变化后不能继续旧确认。
4. **不代控制 Agent。** 不启动、不发送任务、不审批、不替用户 `/reload` 或 `/hooks` 信任。
5. **不覆盖私人数据。** 只处理可证明属于本产品且符合条件的内容；用户改动及不确定残留保留。
6. **对话隐私不进入前端。** 不设计正文预览、私有命令复制、凭据查看或“调试日志全文”。
7. **撤回不夸大。** 暂停、解绑、移除、删除资产分别有不同后果，不能共用一个模糊“关闭”动作。
8. **未成功就保留恢复路径。** 结果不确定时不能清空表单、隐藏记录或给不可撤销的成功视觉。

设计空间：用清楚的对象、分组、动作名称和必要短句表达这些事实；低频明细按需查看。不要把本节八条复制成八张“安全说明”卡。

## 14. 文案、无障碍与响应式约束

### 文案与层级

- 主层回答：现在看什么、当前怎样、下一步能做什么。
- 一个事实只出现一次。同一目录不以文件绝对路径、父目录、说明段再重复三遍。
- 不添加“管理你的……”“在这里你可以……”这类装饰副说明。
- 不把工程模块名、状态枚举、事件名作为普通用户常驻信息。
- 不为显而易见的操作持续弹成功提示。
- 折叠不是垃圾桶；不重要且重复的内容直接删除。
- 需要代码/事件等明细时，让用户主动查看；它们不能压过确认/取消。
- 不用“已添加”“已配置”替代真正的在线状态。

### 可访问与输入

- 图标操作有明确可访问名称；颜色、悬停和 3D 命中不能是唯一操作方式。
- 首页模型选择有 HTML 键盘等价入口；表单有名称，状态与错误可被辅助技术感知。
- 对话框焦点在内部，关闭后回到合理入口；Escape 不绕过正在提交的操作边界。
- 上一步保留输入，禁用控件应能理解原因；不要把不可用动作直接装成正常可点。
- 支持减少动画；动画不能成为读取状态的唯一途径。
- 长连接名、长路径、中文/英文混排、多个安装及多只宠物不能遮住主要操作。
- 400×400 等窄矮窗口允许正文滚动，主操作可达；不要依赖用户把窗口放大才能取消。

## 15. 需要单列提案、不能默默视作现有功能的事项

| 事项 | 当前事实 | 原型处理 |
| --- | --- | --- |
| 每个资产独立命名 | 当前是全局名称偏好 + 绑定名称快照 | 想统一命名需标注数据/产品改动 |
| 完整尺寸范围 | 设置滑条范围与底层范围不同 | 给出统一方案可以，但注明非纯排版变更 |
| 默认空态的行动入口 | 当前有些空态只有一句状态 | 可改善可发现性，不需先新增后台能力 |
| 更清楚的禁用原因 | 当前部分开关仅禁用 | 可用局部提示/语义解决，不恢复满屏副说明 |
| 完成/错误对所有 Provider 一视同仁 | 事实来源不同，不能统一承诺 | 原型必须有未知/不支持分支 |
| 连接预览的表达 | 最新代码删掉了多段解释；功能/授权约束仍存在 | 重设层级，不把旧文案全恢复，也不省略决定所需事实 |
| 完整会话管理、历史、通知中心 | 当前没有 | 若提出，放到非本轮建议，不进入默认设计范围 |
| 手机/Windows/Web 产品 | 当前桌面 macOS 为主 | 窄窗口不等于新增移动端/跨平台承诺 |

## 16. 给设计 Agent 的交付清单

这是**原型覆盖清单，不是要求新增自动化测试用例**。原型应能点击切换关键状态，而不是只给四张静态主屏。

### 页面与状态覆盖

- [ ] 首页：无在线宠物、多连接宠物、单宠物聚焦、退回全景、离线移除、模型失败。
- [ ] 宠物：单资产/多资产、收藏搜索无结果、名称编辑、静态资产、动作选择与重播。
- [ ] 绑定：无连接、未绑定、已使用当前宠物、使用其他宠物、解绑。
- [ ] 导入：选目录、读取中、元信息预览、重选、取消、确认中、失败。
- [ ] 删除资产：确认、仍有绑定时拒绝、失败。
- [ ] 连接：空列表、多条同 Provider、详情、长名称/路径、原位重命名。
- [ ] 扫描：授权、进行中、取消、无结果、多安装、部分受限、重试。
- [ ] 手动添加/换位置：逐阶段输入、返回、重复/无效、保存、取消、不可换位置。
- [ ] pi：读取预览、可写/阻塞预览、等待 `/reload`、在线、暂停、恢复失败。
- [ ] Claude：正常连接、等待新会话、在线、旧陪伴模式、升级任务反馈、受限安装。
- [ ] Codex：扫描候选、精确目标预览、展开脱敏内容、独立审核提示、等待活动、重新扫描。
- [ ] 移除连接：确认、取消、进行中、材料被修改/结果不确定。
- [ ] 设置：五类、所有选项、即时保存、依赖禁用、气泡关闭、恢复默认及失败。
- [ ] 桌宠：拖动、缩放、工具栏、多个独立会话气泡、局部隐藏、全局隐藏、跳转失败。
- [ ] 系统外壳：打开/关闭/后台/退出关系、目录选择器与权限框。
- [ ] 键盘、减少动画、窄矮尺寸、长文本均有对应处理。
