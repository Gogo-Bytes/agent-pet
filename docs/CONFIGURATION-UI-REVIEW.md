# 连接与设置：UI 原型逐项检查

更新：2026-10-14。当前阶段为浏览器 UI 原型验证，等待用户验收本轮视觉。

## 本轮范围

以已经接受的首页、宠物页为视觉基准，只调整连接与设置的内容。保留共享外框、白色页脚和导航；连接不使用 glass，设置不提供桌面预览，关于保持 README / 博客文章结构。短窗口的外框尺寸修复仅在这两个页面生效。

基准元素：明亮蓝紫主色、薄荷与桃粉辅助色、圆润双色图标、轻微按键厚度、明确文字层级。颜色和动效服务于选择与反馈，不给每一项增加装饰或卡片。

## 连接：逐功能批评与修正

| 功能 | 发现的问题 | 本轮处理与验证 |
| --- | --- | --- |
| 已添加配置列表 | 灰梅紫与首页蓝紫割裂；名称、Agent 类型层级弱，进入详情缺少指示 | 蓝紫实体材质；名称加大，类型独立小标记，轻色徽标及右箭头；检查五种 Agent 展示 |
| 自动扫描入口 | 主动作缺少首页按键的厚度和反馈 | 实色渐变、底边厚度、hover / press 状态；与手动添加同等显眼 |
| 手动添加入口 | 与扫描一样重要，但图标与控件质感平淡 | 沿用同等级动作，文件夹图标与手动流程对应 |
| 扫描进度、取消、重新扫描 | 原进度图标可保留；结果页和主列表像两套 UI，空结果会留空白边框条 | 统一结果材质与字号；无结果不渲染空列表。扫描与重新扫描已操作；原生点击在进度态执行取消并返回列表 |
| 扫描添加、命名与确认、完成 | 类型巨图和表单缺少完整层级，主动作质感不同 | 统一徽标底座、标题、输入与动作；实际添加 pi 项目配置；空名称阻止提交 |
| 添加完成后的再次添加 | 扫描草稿在保存后继续复用，移动位置后再次添加可能覆盖旧记录 | 保存后清除草稿；实际执行添加 → 更换位置 → 扫描添加原位置，列表保留两条独立记录 |
| 列表刷新、详情刷新 | 点击区域偏小，状态与操作辨识不足 | 刷新命中区 44×44；验证 OpenCode 从尚未检查转为正常，异常详情保持说明 |
| 配置详情 | 名称与位置像普通后台表单，检查摘要没有语义色彩 | 设计主标题、彩色大徽标与检查反馈区域；正常和缺失位置详情均打开 |
| 重命名 | 表单贴左，留白没有中心，说明文字细小 | 有约束的阅读宽度、居中内容布局、清楚输入与保存反馈；实际保存名称并返回详情 |
| 删除、返回 | 确认删除与普通添加共用同色按钮，风险层级不清 | 删除使用玫粉动作色，保留明确文件不删除说明；检查返回与删除测试记录 |
| 手动步骤、上一步、关闭 | 步骤、标题、动作栏平淡，切步骤需要保留操作位置 | 统一步骤轨道与当前状态；稳定底部操作栏，正文独立滚动；关闭回到发起按钮 |
| 位置输入、选择、折叠帮助 | 输入、嵌套选择按钮、帮助缺少材料层级 | 白色输入底与淡紫操作；检查选择列表、路径粘贴、帮助展开与返回保留 |
| 位置验证 | 大块绿色结果容易误导，重复时成功和错误同时出现 | 重复只显示错误，不出现绿色成功；已实测重复、不可读、格式错误、未知、多类型；缺失状态复核同组件分支 |
| 类型选择 | “重新验证”文案暗示额外按钮，但实际会自动执行 | 文案改为自动验证；实际选择 pi 并验证成功 |
| 手动命名、保存、更换位置 | 小字号和无区分摘要难读 | 增大标签、输入、摘要；实际手动新增、保存改名、编辑位置与返回 |

## 设置：逐功能批评与修正

| 功能 | 发现的问题 | 本轮处理与验证 |
| --- | --- | --- |
| 五个分类 | 图标和选中背景发灰，像后台侧栏 | 彩色图标底座与蓝紫选中指示，逐一打开五分类 |
| 省电、均衡、清晰 | 文案抽象，选择前无法看到实际参数 | 图标底座、选中角标，直接显示 FPS / 清晰度；三个档位均切换 |
| 帧率上限 | 原生控件字号小、层级弱 | 14px 标签与 13px 控件，选择 120 FPS 并确认自定义状态 |
| 渲染清晰度 | 参数与预设关系需确认 | 调整至 75% / 150%，确认当前摘要和预设选中变化 |
| 隐藏时暂停渲染 | 说明太淡，开关没有控件质感 | 说明增大，开关光泽与位置动画；实际切换 |
| 菜单栏图标 | 隐藏入口后的限制需要清楚 | 明确保留入口原因；关闭 Dock 后菜单栏开关禁用 |
| Dock 图标 | 反向入口保护同样需要可读 | 关闭菜单栏后 Dock 开关禁用；实际验证两个方向 |
| 登录启动 | 混在连续表格里不便找 | 分入“启动与退出”，实际切换 |
| 启动时打开控制台 | 与是否启动混淆 | 保留明确说明，独立开关；实际切换 |
| 关闭控制台后继续运行 | 退出应用与关窗口区别需要读得见 | 13px 说明，分组展示；实际切换 |
| 宠物大小 | 系统滑轨与其他控件风格不同 | 自定义进度轨道、圆形滑块与数值标记；键盘调至 105% |
| 宠物常驻桌面 | 与未启动时显示存在隐藏依赖 | 清楚显隐说明；实际关闭并检查依赖 |
| Agent 未启动时显示 | 常驻关闭后仍可设置，生效关系不透明 | 禁用并说明开启常驻后生效；重新开启常驻后恢复操作 |
| 宠物名称 | 混在无分组表格中 | 分入桌面显示，实际切换 |
| 始终置顶 | 与动作、提醒没有区别 | 分入桌面显示，实际切换 |
| 气泡 | 与提醒依赖容易忽略 | 分入动作与气泡；关闭后提醒页展示快捷开启，实际执行 |
| 减少动画 | 应与显示设置分开 | 分入动作与气泡，实际切换 |
| 任务完成、任务出错 | 说明太淡，与场景状态层级不一致 | 保留明确独立开关与较大说明；分别切换 |
| 恢复默认、取消、确认恢复 | 原按钮被替换后焦点丢失 | 进入确认聚焦取消，结束回到恢复按钮；取消与确认均实际执行 |
| 关于、版本、正文 | 文章层级可以更清楚，但不应改回营销页 | 保留原文，版本小标记、章节短色线；滚动阅读全文 |
| GitHub 链接 | 应保持文章中的链接语义 | 保留外部链接与可见焦点；验证 href 为项目仓库，未操作外站 |

## Main 与独立复查

Main 实际浏览并操作上述流程；独立 Agent 读取首页/宠物基准及修改后的桌面截图，复核连接、设置源码。复查提出的刷新点击范围、空结果边框、恢复默认焦点均已修复。没有用独立源码审查冒充浏览器点击验证。

响应式检查：1280×800、390×844、1024×600。

- 390px 宽：无整页水平溢出，分类横向浏览，内容纵向滚动。
- 1024×600：曾发现外框最低 620px 将页面撑至 748px；修复后整页高度 600px、scrollY 为 0，外框在 y=28…572。
- 设置宠物页滚动：右内容 scrollTop=448，左侧分类和顶部/页脚保持在窗口内。
- 弹窗短窗口正文独立滚动，关闭与底部动作始终可见。

验证：`pnpm typecheck`；`pnpm exec vite build --config apps/desktop/vite.prototype.config.ts`；`git diff --check`。本轮不接入真实扫描、系统偏好或 Electron。
