# 连接与设置：菜单重构与实际验收

更新：2026-10-14。状态：**Web mock 原型已完成本轮实施与浏览器检查，用户视觉验收待确认**。此记录覆盖上一轮“渐变、厚底按键”内容区方案；不代表正式桌面接入或真实 Provider 验收。

## 范围与整体方向

仅重构连接、设置内部。首页、宠物、共享外框、顶部栏、底部白色页脚、导航及导航动画的源码未修改。原有短窗口尺寸规则原样保留。连接无 glass、宠物场景、工作监控；设置无桌面预览。所有配置与偏好仍为浏览器内存 mock，刷新会重置；没有文件读取、扫描、系统偏好、Electron 或新依赖。

采用浅色掌机菜单：深紫墨色表示当前选择，浅纸色提供阅读表面，彩色小标识区分 Agent；细边界、留白和字重建立层级。移除内容区的渐变按钮、底边厚度、内高光与重复表格分隔。菜单选择、详情、参数、错误、焦点和动效作为一套系统：hover 不改变当前项；选择轻微横移出现，按钮按下短促反馈；系统减少动画时停止过渡。连接选择和设置类别不改变首页所选 Agent。

连接桌面为“配置选择菜单 + 当前详情”，窄窗口选择后进入详情并提供返回。选择菜单显示名称、类型、短位置与检查图形，完整位置及修复操作集中在当前详情。扫描与手动添加常驻同权重入口。扫描结果仍按目标区分安装/项目；添加保留命名确认、完成页和返回。

设置为固定分类目录 + 独立滚动的内容区。画质用三档选择带，手调使用真实单选分段；大小使用数值与滑轨；布尔偏好使用可直接点选的“开 / 关”。软件入口并排比较，其他选项按目的分组。关于保留博客 / README 文章、版本、介绍、进展、使用方法、隐私和 GitHub 链接。

## 旧版问题与本轮修正

| 功能 | 旧版实际问题 | 本轮处理 |
| --- | --- | --- |
| 配置列表与详情 | 列表同时铺名称、路径、标签、箭头和刷新；详情又重复名称与状态 | 紧凑选择菜单；当前详情呈现完整信息；刷新集中在检查区域 |
| 自动扫描 / 手动添加 | 厚底渐变按钮只有材质变化，入口没有完整设计 | 同尺寸操作入口、对应线条图标、具体副标题与方向反馈 |
| 扫描候选、确认、完成 | 普通后台结果行；确认按钮挤到页脚；巨大徽标占空间 | 候选按配置目标呈现；紧凑确认表单；完整位置、名字、动作；保留草稿与完成入口 |
| 重命名 / 删除 | 大片无功能空白；“删除配置”容易让人想到磁盘文件 | 有约束的表单宽度；“移除配置”确认说明只删除产品记录；取消与返回均可用 |
| 手动位置 / 验证 | 伪 3D 图标、控件和三屏文案缺少统一；错误只能返回 | 不透明平面弹窗、紧凑步骤、正文滚动、固定动作；权限/格式错误可原位重新检查 |
| 设置档位与数值 | 画质选项与普通开关表单割裂；参数隐藏后缺少明确状态 | 同一选择语言；当前组合摘要；帧率/清晰度独立单选；自定义组合不冒充预设 |
| 软件 / 宠物 / 提醒 | 连续分隔线与开关；重要依赖混在小字说明里 | 有目的的分组与直接选择控件；入口保护、常驻依赖和气泡依赖紧邻相关选项 |
| 恢复默认 | 行内确认挤在正文尾部 | 分类区固定入口；独立模态确认；解释范围、默认聚焦取消、关闭回入口 |
| 关于 | 原文章结构已经正确，装饰分散阅读 | 保留文章内容，统一标题、段落和普通链接；分类可访问、正文独立滚动 |

## Main 实际操作检查

下面是浏览器操作结果，不是通过阅读源码推定。默认数据为六类 Agent / 八个候选，默认五个已添加配置；扫描排除已缺失的 Gemini 位置，显示七个候选。

| 范围 | 已实际操作的路径与结论 |
| --- | --- |
| 连接选择与检查 | pi、Codex、Claude、Gemini、OpenCode 可选择；OpenCode 从未检查转为可用；Gemini 刷新仍缺失；刷新不改变通信状态；桌面选择保留菜单焦点 |
| 扫描 | 进度、取消、重新扫描、结果、已添加标记；添加第二套 pi；返回重选保留自定义名称；确认、完成、查看配置与返回列表 |
| 手动正常路径 | 位置输入、打开选择器、选 Cursor、自动验证、命名确认、新增；多类型选 Codex 后自动重验；未知位置选 pi 后重验；新增记录不覆盖已有记录 |
| 手动错误与恢复 | `/demo/missing`、`/demo/private`、`/demo/broken.json`、相对路径、重复 `~/.pi/agent` 与尾斜线路径；错误阻止下一步；权限错误原位重查仍诚实报错；上一步修改位置恢复正常 |
| 名称与位置 | 空名称阻止保存；重命名通过 Enter 提交；更换 Codex 位置保留名称、记录 ID 与健康字段；确认返回保留输入；跨首页/连接切换和浏览器前进后退保留内存配置 |
| 移除与空状态 | 取消保留记录；确认仅移除选中的记录；空列表保留两种添加入口；无扫描结果可重新扫描或进入手动添加；失效详情可返回列表 |
| 渲染 | 三档逐项选择；120 FPS / 75% 成为自定义；清晰度与帧率可分别改变；隐藏时暂停可选择；方向键切参数且不触发原型方案切换 |
| 软件 | Dock 关闭后菜单栏不能关闭；反向保护同样成立；登录启动、启动打开控制台、关闭窗口继续运行均可修改；点击已选“开”仍保持开启 |
| 宠物 | 大小通过键盘从 100% 到 105%；常驻关闭后离线显示禁用并说明原因；恢复常驻后可修改；名称、置顶、气泡、减少动画均逐项修改 |
| 提醒 | 完成与出错分别切换；关闭气泡时提醒说明依赖并保留偏好；快捷开启后恢复气泡且焦点进入提醒选项 |
| 恢复与键盘 | 取消、Esc、确认恢复；Tab / Shift+Tab 在弹窗内循环；关闭回到入口；恢复后所有偏好回默认且连接不受影响；手动弹窗同样具备循环与返回焦点 |
| 关于 | 五分类均可访问；阅读全文并到达项目链接；版本为构建注入的 0.1.0；GitHub href 指向项目仓库，未操作外站 |

用于重复验收的 URL 参数只在连接组件内部选择 mock 初态，不显示产品工具栏：`configDemo=empty`（空列表）、`missing`（无扫描结果）、`waiting`（尚未检查）、`error`（格式异常）。普通入口不带此参数。类型识别仍是 mock；自选完整位置可以配合类型选择体验流程，不代表读取或验证了真实文件。去重对 mock 路径去空白、重复斜线和尾斜线，不宣称真实文件系统 canonicalization 或符号链接识别。

## 响应式、截图与独立挑刺

Main 实看 1280×720、1280×800、1024×600、1280×480、390×844，以及最终分类复验 390×720。

- 1280×720：五个默认菜单项完整可见；详情高度与可用内容区均为 365px，不需要滚动寻找刷新、位置或移除。配置更多时选择区可独立滚动。
- 1024×600：文档高 600px、scrollY=0，外框 y=28…572；内容滚动，顶部与白色页脚保持可见。
- 390×844：文档宽 390px、无水平溢出；连接为选择→详情，设置五分类在窄窗口同屏可访问；关于内容 scrollTop=662 时外层 scrollY 仍为 0，分类 top 仍为 77px。
- 1280×480：长路径在模态正文内换行；正文 clientHeight=245、scrollHeight=311、scrollWidth=clientWidth=618；操作栏下沿 459px，在 480px 视口内。
