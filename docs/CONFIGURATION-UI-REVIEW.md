# 连接与设置：菜单重构与实际验收

更新：2026-10-14。状态：**Web mock 原型已完成本轮实施与浏览器检查，用户视觉验收待确认**。此记录覆盖上一轮“渐变、厚底按键”内容区方案；不代表正式桌面接入或真实 Provider 验收。

## 范围与整体方向

仅重构连接、设置内部。首页、宠物、共享外框、顶部栏、底部白色页脚、导航及导航动画的源码未修改。原有短窗口尺寸规则原样保留。连接正文采用实体表面；按用户后续批注，仅手动添加入口复用圆形 glass 图标按钮。无宠物场景或工作监控；设置无桌面预览。所有配置与偏好仍为浏览器内存 mock，刷新会重置；没有文件读取、扫描、系统偏好、Electron 或新依赖。

采用浅色掌机菜单：接近品牌的蓝紫表示连接当前选择，浅纸色提供阅读表面，彩色小标识区分 Agent；细边界、留白和字重建立层级。移除内容区的渐变按钮、底边厚度、内高光与重复表格分隔。菜单选择、详情、参数、错误、焦点和动效作为一套系统：hover 不改变当前项；选择轻微横移出现，按钮按下短促反馈；系统减少动画时停止过渡。连接选择和设置类别不改变首页所选 Agent。

连接桌面为“配置选择菜单 + 当前详情”，窄窗口选择后进入详情并提供返回。选择菜单显示名称、类型与检查图形；按用户后续批注删除短位置，完整位置及修复操作集中在当前详情。扫描与手动添加常驻，分别使用文字胶囊与圆形 glass 加号入口。扫描结果仍按目标区分安装/项目；添加保留命名确认、完成页和返回。

设置为固定分类目录 + 独立滚动的内容区。画质用三档选择带，手调使用真实单选分段；大小使用数值与滑轨；布尔偏好使用无文字开关，功能名称与必要依赖说明位于控件外。软件入口并排比较，其他选项按目的分组。关于保留博客 / README 文章、版本、介绍、进展、使用方法、隐私和 GitHub 链接。

## 旧版问题与本轮修正

| 功能 | 旧版实际问题 | 本轮处理 |
| --- | --- | --- |
| 配置列表与详情 | 列表同时铺名称、路径、标签、箭头和刷新；详情又重复名称与状态 | 紧凑选择菜单；当前详情呈现完整信息；刷新集中在检查区域 |
| 自动扫描 / 手动添加 | 厚底渐变按钮只有材质变化，入口没有完整设计 | 同尺寸操作入口、对应线条图标、具体副标题与方向反馈 |
| 扫描候选、确认、完成 | 普通后台结果行；确认按钮挤到页脚；巨大徽标占空间 | 候选按配置目标呈现；紧凑确认表单；完整位置、名字、动作；保留草稿与完成入口 |
| 重命名 / 删除 | 大片无功能空白；“删除配置”容易让人想到磁盘文件 | 有约束的表单宽度；“移除配置”确认说明只删除产品记录；取消与返回均可用 |
| 手动位置 / 验证 | 伪 3D 图标、控件和三屏文案缺少统一；错误只能返回 | 不透明平面弹窗、紧凑步骤、正文滚动、固定动作；权限/格式错误可原位重新检查 |
| 设置档位与数值 | 画质选项与普通开关表单割裂；参数隐藏后缺少明确状态 | 同一选择语言；当前组合摘要；帧率/清晰度独立单选；自定义组合不冒充预设 |
| 软件 / 宠物 / 提醒 | 连续分隔线与开关；重要依赖混在小字说明里 | 有目的的分组与直接选择控件；入口保护、常驻依赖和气泡依赖紧邻相关选项 |
| 恢复默认 | 行内确认挤在正文尾部 | 分类区固定入口；独立模态确认；解释范围、默认聚焦取消、关闭回入口 |
| 关于 | 原文章结构已经正确，装饰分散阅读 | 保留文章内容，统一标题、段落和普通链接；分类可访问、正文独立滚动 |
