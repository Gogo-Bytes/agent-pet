# 连接页视觉研究：简单配置，娱乐产品的完成度

日期：2026-10-13。范围：方案 A 浏览器原型、内存 mock；不接 Electron，不扫描真实配置，不安装依赖。已阅读 [MVP 执行计划](MVP-EXECUTION-PLAN.md) 和 [产品方向](PRODUCT-DIRECTION.md)。

**最新用户澄清优先：** 连接页的交互是简单可靠的配置流程，视觉仍属于娱乐产品。去掉大号“连接”标题，直接分配空间给 Agent 身份、连接情况和一键扫描。这里没有宠物、房间或 3D 场景，也不需要浮层大卡片。

本文区分“来源事实”和“设计推论”。建议是面向本项目的取舍，不宣称参考产品也采用同一种配置流程。

## 1. 研究结论

**设计推论：** 当前要补的不是更多背景特效，而是完整的身份与反馈语言：彩色 Agent 标识、明确状态形状、稳定的选中层、短促且连续的动作反馈、精细的字体和空间关系。简洁的配置列表完全可以达到游戏菜单和娱乐平台的完成度。

- 页面顶端成为紧凑操作带：左侧实际数量/需要处理数，右侧一键扫描。底部已有导航表达当前位置，大标题不再重复。
- 主体使用直接铺开的“配置列表 + 当前详情”。列表约占可用宽度四成，详情六成；这是起点，按真实内容长度调整。两区用留白和细分隔识别，不套浮层玻璃卡片。
- 多个 Agent 的视觉身份来自圆角徽标、柔和底色和一致尺寸。品牌颜色只占小面积；状态另有固定颜色和图形，避免“紫色是品牌还是连接中”的歧义。
- 扫描发生在当前布局内，主按钮原位变成扫描状态，列表显示结果；不要弹窗、全屏遮挡或重复向导开关。
- 常态不持续炫动。只在扫描、选中切换和用户动作后反馈，完成即停止。

## 2. React Bits：实际组件源码检查

核对 [官方组件网站](https://reactbits.dev/components/animated-list)、[官方仓库](https://github.com/DavidHDev/react-bits)，并将下面源码链接固定在研究时 GitHub API 返回的 commit `496968c4117e21278f13917201b7d615bc5e7450`。不是凭旧版组件介绍推断依赖；没有运行或安装这些组件，也没有实测性能。

### Animated List

**来源事实：** 当前 TS/CSS 源码依赖 React、`@hugeicons/react`、`@hugeicons/core-free-icons`，没有导入 Motion。单独选中指示层用 rAF 更新位置，运动收敛后停止；列表有 ResizeObserver、进入视口检测、键盘逻辑。`selectOnHover` 默认开启。减少动态效果时选中位置直接落位、进入动画降为 fade；媒体偏好在初始化读取，键盘滚动仍指定 smooth。[TS 实现](https://github.com/DavidHDev/react-bits/blob/496968c4117e21278f13917201b7d615bc5e7450/src/ts-default/Components/AnimatedList/AnimatedList.tsx)、[CSS 实现](https://github.com/DavidHDev/react-bits/blob/496968c4117e21278f13917201b7d615bc5e7450/src/ts-default/Components/AnimatedList/AnimatedList.css)。

**设计推论：适合借机制，不照搬整套列表。** 使用单个、随选中项滑移的浅紫光带；点击才改变当前配置，hover 只高亮。保留本项目圆润图标和原生按钮语义，不为默认文件管理器图标安装新库。长列表不需要滚动时反复缩放弹入，更不应鼠标掠过就切详情。选中光带不能让行高、列表宽度或详情高度改变。

### Spotlight Card

**来源事实：** 当前实现只有 React 与 CSS 导入。rAF 计算柔光和边缘光，直接改渐变样式；停稳时可以停止。启用 ambient 时可见元素持续运行；初始化检测 reduced motion 后去掉漂移与平滑跟随，保留静态光响应。每帧可能读取元素矩形并重写渐变，因此不能仅凭“无动画库”称其零成本。[TS 实现](https://github.com/DavidHDev/react-bits/blob/496968c4117e21278f13917201b7d615bc5e7450/src/ts-default/Components/SpotlightCard/SpotlightCard.tsx)。

**设计推论：局部适用。** 借鉴轻微边缘受光给主扫描按钮或选中身份徽标；连接列表不需要每行跟踪鼠标的聚光灯。当前页面没有 3D 背景，不再创造一堆浮层卡片来承载 Spotlight。静态渐变 + hover opacity 更符合本轮需求，也更容易验证。

### Star Border

**来源事实：** 当前 TS 版本是 React + Canvas 2D，不是仅用 CSS 旋转渐变。实现绘制边缘光尾、脉冲和可选粒子，限制 DPR 至 2，IntersectionObserver 控制可见性；reduced motion 停止巡游和粒子，但点击脉冲仍可触发。默认可见边框有巡游，因此多个常态按钮会有多个 Canvas 绘制循环。[TS 实现](https://github.com/DavidHDev/react-bits/blob/496968c4117e21278f13917201b7d615bc5e7450/src/ts-default/Animations/StarBorder/StarBorder.tsx)、[CSS 实现](https://github.com/DavidHDev/react-bits/blob/496968c4117e21278f13917201b7d615bc5e7450/src/ts-default/Animations/StarBorder/StarBorder.css)。

**设计推论：借鉴有限扫光，不直接复制。** 仅“一键扫描”运行时出现一条短扫光，结束后固定结果；可用伪元素 transform 实现。常态按钮不沿边缘永远跑灯，页面也不布满闪星。减少动态效果时用稳定图标和“扫描中”文本。

### Magnet

**来源事实：** React 原生弹簧 + rAF，使用共享注册表和 pointer 监听；运动收敛后停止，触摸指针不启用磁吸，初始化 reduced motion 禁用位移。默认作用距离 100px，内层可跟随指针移动。[TS 实现](https://github.com/DavidHDev/react-bits/blob/496968c4117e21278f13917201b7d615bc5e7450/src/ts-default/Animations/Magnet/Magnet.tsx)。

**设计推论：本页不采用。** 添加、重新检查、移除都是精确配置操作。按钮追鼠标会让位置不稳定；娱乐感应通过按下回弹和图标反馈表达。即使可限制幅度，也没有足够用户收益支持增加这一机制。

### Stepper

**来源事实：** 当前源码导入 React 与 Hugeicons，使用 Web Animations API、ResizeObserver 管理步骤、选中轨道与内容高度；reduced motion 降为 fade，仍可能执行较短的高度动画。[TS 实现](https://github.com/DavidHDev/react-bits/blob/496968c4117e21278f13917201b7d615bc5e7450/src/ts-default/Components/Stepper/Stepper.tsx)。

**设计推论：借连续性，不引入庞大步骤横幅。** 在同一详情区从发现结果到确认，再到检查结果；保留返回和已选配置。内容变化用约 180–240ms 淡入，列表与操作带位置不跳动；默认不添加只有开发者才关心的五阶段进度仪式。

### 授权和落地边界

**来源事实：** 固定版本许可证标为 MIT + Commons Clause，允许作为应用/网站/产品的一部分使用，要求保留相关声明，对组件自身的售卖、再许可、再分发附加限制。因此不能把它概括成“纯 MIT，任何用途无条件”。[实际许可证](https://github.com/DavidHDev/react-bits/blob/496968c4117e21278f13917201b7d615bc5e7450/LICENSE.md)。这只是对条款的简要记录，不是法律意见。

**本轮建议：** 参考设计机制并用既有 React/CSS 和本项目 Icon 独立实现。直接复制代码时应保留许可，并重新核对具体引入版本与依赖；本次研究不授权安装依赖、采购 Pro 或发布第三方组件库。

## 3. 第一方娱乐/游戏设计资料

### Discord：趣味视觉可以服务实用界面

**来源事实：** 官方品牌说明将更鲜明、活泼的色彩与在线、离开、勿扰状态联系起来；App 内变化更克制，色彩为明暗主题可读性进行调整，并不要求与营销图完全一致。[官方设计说明](https://support.discord.com/hc/en-us/articles/1500009438682-A-Fresh-New-Look-to-Celebrate-Our-6th-Birthday)。

**设计推论：** Agent Pet 保持浅紫场底与白色页脚，主操作增强紫色饱和度，Agent 身份使用小面积薄荷、桃色、蓝紫徽标。状态使用图标 + 文字，颜色做辅助；禁止把参考资料里的品牌红绿直接变成全页状态背景。正文继续使用清晰的紫灰，不用装饰性渐变文字、超细字重或每行一句陪伴文案。

### Nintendo：用身份图标和区域秩序表达层级

**来源事实：** 官方 Switch 2 HOME 说明把用户入口、软件图标、底部系统入口及右上系统状态分成区域；其功能包含启动软件与配置系统，并未把所有操作都改成文字大标题。[官方 HOME 结构](https://www.nintendo.com/au/support/articles/nintendo-switch-2-home-menu-overview/)、[Nintendo of America 官方导览视频](https://www.youtube.com/watch?v=MFUh-KhOhMs)。本轮依据官方结构说明，不声称测量了实际游戏机或视频逐帧动效。

**设计推论：** 首页/宠物/连接继续共享稳定底部入口。连接页将空间让给可识别的 Agent 标志和当前动作；不把配置项改成巨大游戏封面矩阵。参考的是区域秩序和图标身份，不是照抄游戏机菜单。

### Xbox：游戏菜单也必须易懂，动效不能妨碍阅读

**来源事实：** XAG 112 要求一致、直觉的菜单顺序和可预测焦点，包含辅助输入与返回路径。XAG 117 要求对非核心移动/闪烁内容提供停止或关闭方式，说明文字后的运动背景也可能妨碍阅读。[UI 导航](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/112)、[视觉干扰和动态设置](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/117)。

**设计推论：** 彩色菜单不等于控制器式复杂导航；本项目保留普通按钮、键盘焦点和明确返回。扫描动效位于图标/局部轨道，配置路径和错误提示背后没有持续移动。prefers-reduced-motion 需要完整覆盖扫描、选中滑移和弹入，不应只检查动画库是否带开关。

## 4. 本轮可落地视觉规格（设计推论）

| 元素 | 具体表达 | 解决的问题 |
| --- | --- | --- |
| 顶端操作带 | 数量、异常数量与扫描主动作；不写大号“连接” | 页面顶端不浪费高度 |
| Agent 身份 | 约 44–52px 圆角标记、准确名称、配置别名；背景小面积品牌色 | 多类型快速识别，不是千篇一律后台文字行 |
| 配置列表 | 紧凑两行，第二行仅别名/位置摘要；选中光带与细描边 | 扩容到多个类型和长路径 |
| 状态 | 工作中小条形图标、待命点、等待时钟、中断断链；每个带简短文字 | 颜色以外也能看懂；连接与工作状态区别 |
| 详情身份区 | Agent 图标与名称优先，状态紧接其后；无需再重复页面标题 | 趣味来自排版、色彩和身份 |
| 详情内容 | 状态与最近反馈一组，配置位置一组；必要说明一行 | 内容分组清晰，减少段落废话 |
| 配置路径 | 视觉缩略，完整路径可展开/读取；样式不伪装成可编辑输入 | 少技术噪声但能判断目标 |
| 扫描 | 按钮原位变扫描态，结果区局部扫光/逐项出现，完成后停止 | 可感知正在查找，没有打断 |
| 操作反馈 | hover 轻亮、press 小幅缩放、成功勾选单次绘制 | 娱乐产品的手感，位置保持稳定 |
| 材质 | 轻亮渐变与细边缘高光；glass 仅用于需要区分的少数控件 | 统一前两页语言，避免无场景却大量浮层 |
| 窄屏 | 列表与详情顺序切换，操作带允许自然换行；页脚持续保留 | 避免挤压和叠层 |

建议起始动效：hover 120–160ms，press 100–140ms，选中切换/详情淡入 180–240ms。数值为本项目验证起点，不是官方规定。不要让名称、路径和说明整段弹跳；文字应尽快可读。扫描时间由 mock 状态决定，视觉不得制造真实扫描/接入已完成的假象。

## 5. 验收与自评清单

1. 去掉“连接”大标题后，用户仍能通过页脚知道在哪；首屏直接看出几个配置及下一步动作。
2. 8 个 mock 配置并存时，名称、状态、位置摘要不抢同一层级；长路径不会撑破宽度。
3. Agent 品牌色与运行状态色互不冒充；中断、等待、工作中的图标与文字可以独立理解。
4. 列表选择只切详情，不变首页当前 Agent；hover 不改变配置选择。
5. 页面不出现雷达、房间、宠物、卡片套卡片或营销式大段解释。
6. 扫描在当前页内开始/停止/展示结果；未配置、配置完、等待启动、收到状态仍是独立证据。
7. 缩小窗口时标题、按钮和路径没有重叠；页面切换不会重建底部 tabs 或丢失流程。
8. 键盘焦点清晰，只有图标的按钮有 accessible name 与 tooltip；移除不靠 hover 才能获得操作。
9. reduced motion 使用静态状态提示，禁用位移与无限扫光；隐藏页面没有继续运行的装饰循环。
10. 自评对照首页/宠物：同一字体、紫灰正文、图标线条、圆角节奏和白页脚；不能只因为背景是紫色就宣称统一。

**研究证据范围：** 已检查上述第一方说明和固定源码，未安装/运行 React Bits、未做 FPS/电量测试、未访问真实 Agent 配置。视觉可用性需要 Main 在原型浏览器里继续实际检查，本文件不代替成品验收。
