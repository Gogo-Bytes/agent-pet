启动：`pnpm prototype --port 4175`。

## 本轮审查结论（2026-10-14）

Main 浏览器实走，两位独立 subagent 分别审查配置/设置交互、首页/宠物及最终四页截图；另由独立实现 agent 修复配置覆盖问题。四页保留已确认外框、白色页脚及常驻滑动导航。场景小型悬浮操作保留 glass；收藏、绑定、连接和设置内容为实色。关于使用 README 正文。没有改正式 Electron 实现。

已修复的具体问题：

- 首页/宠物原来只显示固定三类 Agent：改为消费每条连接记录，保留稳定 ID、名称、类型、状态；新增、重命名和删除同步。选择器搜索、内部滚动并按场景剩余高度约束；同类型配置可区分。
- 扫描草稿保存后再次使用，覆盖已移动配置：只复用未保存草稿，保存清理草稿，新增分配未占用 ID。
- 试播“睡觉”污染首页“工作中”：首页动作根据状态派生，宠物试播独立保存；共享场景容器继续常驻。
- 解绑仍自动展示星星：显示未选择宠物及选择入口；删除当前 Agent 时选择回到存在的配置。
- 弹窗方向键切换旧原型并丢状态：移除全局方向键方案切换，A 的演示工具默认隐藏（仅 `demo` 参数开启）。
- 底部 tabs 无键盘支持，连接页又抢焦点：加入左右/Home/End、roving tabIndex、tabpanel关联；从导航进入连接时保留导航焦点。
- 动作浮层/Agent 选择器 Escape 丢焦点：返回触发器，展开后搜索获焦，点击外部收起。
- 重复位置同时显示成功与错误：只显示重复错误，下一步禁用。未知旧路由返回列表，失效记录可返回。
- 宠物添加原生 alert：改为抽屉内导入未开放说明，不打断浏览器。
- 首页按钮材质和高度与页脚不一致：清理旧强制覆盖，统一主动作颜色、圆角、最小触控区域；首页/宠物桌面页脚实测均72px，场景下沿一致。

## 已执行检查

| 场景 | 结果 |
| --- | --- |
| pi项目配置添加→移动→再次扫描原位置 | 两个独立ID和位置均保留，列表由5增至7，无覆盖 |
| 重命名→首页搜索 | 新名称可选择，同类型配置不合并 |

| 宠物绑定/解绑→首页 | 绑定可见，解绑显示明确空状态 |
| 睡觉试播→Escape→工作中首页 | 焦点回动作入口，首页实际 `motion-work` |
| 连续方向键经过四页 | 焦点留在导航，可经过连接到设置 |
| 收藏选中、空搜索、Esc关闭 | 选中不关闭；空结果有提示；收起后焦点回入口 |
| 手动重复位置 | 错误单独展示、下一步禁用、关闭恢复入口 |
| 设置及关于 | 实色、无桌面预览、仅右侧正文滚动；README结构保留 |
| 1280×720 / 390×844 | 检查四页及抽屉/动作浮层、原生手动弹窗；没有确认的新遮挡问题 |

独立视觉审查曾提出宠物标题裁切疑点；Main 重拍并测量标题高度55.296875px、overflow visible，原尺寸截图完整。审查者复看后撤回该疑点，没有盲加固定标题高度。

## 用户可重点验收

1. 首页打开 Agent 选择器，搜索不同类型；连接页新增或重命名后再回来选择。
2. 宠物上一个/下一个、收藏矩阵、动作切换，检查抽屉不会选完就关闭。
3. 在连接页手动添加、返回修改、重复位置、重命名与删除。
4. 设置不同分类、长内容右侧滚动，以及关于正文的阅读体验。
