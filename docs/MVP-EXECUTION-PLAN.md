# 当前 MVP 执行计划

目标是单用户、本机 macOS 上可独立运行的 Agent Pet，先完善 pi、Claude Code、Codex CLI 的被动观察，再推进后续功能。当前行为见[产品需求](../PRODUCT-REQUIREMENTS.md)，版本和能力见各 [Provider 模块](README.md#agent-接入)。不以目录、自动化通过或局部用户确认推导所有宿主、事件和原生场景均已支持。

## 当前优先级

以下三项已迁入 GitHub；**动态状态、阻塞和验收结果只在对应 Issue 维护**，本文不复制进度表：

1. [#15 三种 Provider 最近适配增量：独立审查与有界原生验收](https://github.com/Gogo-Bytes/agent-pet/issues/15)。优先收尾现有 pi / Claude / Codex 链路。
2. [#16 Provider 细类来源：业务重试与输出限制](https://github.com/Gogo-Bytes/agent-pet/issues/16)。依据见[版本化来源与能力限制](PROVIDER-ANIMATION-EVIDENCE.md)；没有可靠事实就保持未知，不更换 SDK/RPC 宿主或解析正文补信号。
3. [#17 持续状态动画 in / loop / out](https://github.com/Gogo-Bytes/agent-pet/issues/17)。Provider 收尾之后实施；[确认设计](PET-ANIMATION-TRANSITIONS.md)仅覆盖 idle、working、dragging，当前映射仍是字符串/null。

**离线素材制作与拼接暂停。** 不继续用户模型的其他尾段修订或 Blender 拼接；这不同于已经确认、等待实施的 #17 播放器功能。不得自动修改、安装、重绑或上传用户模型。

## 尚未迁入 Issue 的范围

下列是仍需保留的后续工作，不是旧阶段重做清单；具体任务开始前收窄范围，跨轮跟踪再按授权迁移：

- **原生反馈与生命周期补验**：在 #15 最近增量范围之外，按已支持事实补 pi 等待、整轮错误、压缩/输出限制、`/reload` 身份连续性，Claude 查找/工具错误、退出与并发，以及多 Provider 的下一轮、重连和真实动画反馈。未知能力不列为可强行测出的功能；Codex 独立错误受[接口限制](CODEX-ERROR-FEEDBACK-LIMIT.md)约束。
- **日用稳定性与资源**：长时间运行、系统重启/睡眠唤醒、多配置/多窗口、资产切换后的 GPU/缓存释放、崩溃恢复；本机显示器/DPI/Space/全屏层级、命中穿透、键盘与辅助功能。当前 Renderer 自动恢复有次数上限，不能当作无限恢复保证。
- **macOS 设置与独立应用包**：软件开关实际效果、重启后偏好、登录项（另行授权）、最新源码外 `.app` 的完整交互与部署/选择性撤回。开发模式正常或启动 smoke 不替代这些检查，硬件功耗仍需测量。
- **Antigravity CLI**：先取得官方事件/扩展、版本与隐私边界证据；此前检索受限不证明官方没有接口。有可靠来源后才分阶段适配，当前不启动真实安装/模型操作。
- **桌面宿主**：Codex、Antigravity 桌面端放在 CLI 之后，各自核对官方观察入口、身份与配置边界；CLI 通过不等于桌面端支持。Windows 仍为后续平台。
- **资产管理扩展**：迁移/备份说明、导出/升级/恢复和失败残留处理尚无完整承诺；资产显示名与绑定名称的进一步统一也不从旧草案自动生效。先确认需要的产品范围，当前不自动接管同名目录或删除未知残留。
- **生产化与分发**：依赖安全审计及需授权的升级、完整跨用户/socket ACL/peer 身份、原生 syscall 故障、持久性、签名/公证/更新及最终包权限验证延期；要求见[安全边界](SECURITY-BOUNDARIES.md)。自动 repair/reset/revoke-all 仍未批准、未实现。

## 不变的执行与权限边界

- 只观察，不启动、接管、审批或控制 Agent；不采集 prompt、响应、工具正文或 transcript。秘密不进入 Renderer、日志、诊断、提交或公共应用包。
- 真实目标操作前明确**精确目标、读取/写入范围、变更预览、生效条件、撤回方式**并取得授权。只读同意不是部署许可，旧命令/旧批准不是当前操作授权；Agent/模型请求、日常配置、依赖安装/升级、系统设置与发布分别核对范围。
- 未知文件、用户修改、凭据、配置及不确定残留必须保留。停止观察不等于卸载运行中的扩展，清理或持久化失败不能报告完全成功。
- **完整 D6 仍 BLOCKED。** 生产安全与正式发布门槛不决定本地 MVP 排期，但不能删除 guard/数据保留测试、绕过 `acl-unverified`、接入测试 policy 或宣称这些要求已通过。
- 桌面和首页仅展示在线且显式绑定的配置，离线/解绑立即移除；`attention` 仅回退、`disconnected` 无自动可见载体，latest-wins 不保证每个短反馈完整播出。改变这些规则需新的产品决定。
- 实现与验证按[工程规则](../AGENTS.md)执行；文档检查不冒充功能测试，自动化、原生交互、GPU与用户验收分别判断。阶段本地提交不等于推送、PR、合并、关闭 Issue 或发布授权。
