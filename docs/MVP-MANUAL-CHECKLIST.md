## 填写规则

- `[x]` 只表示该项实际操作通过；失败、阻塞、未测保持 `[ ]`，在结果区记录。
- 每条结果格式：`编号｜通过/失败/阻塞/未测｜实际表现｜截图或日志位置`。
- 不粘贴 token、生成扩展的完整源码、对话正文或含凭据的环境变量。
- 本清单不是对 Agent 的真实目标操作授权；本轮由用户操作。
