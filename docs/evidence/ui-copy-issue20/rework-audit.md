## 用结构纠正重复错误

本任务在 `d7f00c3`、`9c6902c`、`2ec43c1` 的多轮删句后仍被用户否定，说明只写规则和缩句不够。

- **确认流程**：用现有原生 Dialog 把一次决定与详情浏览分开，保留取消、焦点恢复、禁用和错误反馈。
- **路径呈现**：新增很小的 `FileChanges`，pi/Claude 共用，不再让调用方复制一组完整路径盒子。仅缩短明确位于根目录内的显示值，原始数据不变。
- **说明槽**：删除设置分组的副说明参数，类型检查不再允许按旧接口随手加回说明。
- 不能用类型系统判断一段中文是否真正有用；没有添加任意字数 lint，也没有违反仓库约定添加测试。剩余取舍仍需整屏审查。

## 未覆盖与交付边界

本轮隔离 Electron 及浏览器会话已按所有权关闭并清理，未关闭用户其他运行实例。

本轮没有确认扩展/hooks 写入、删除连接、导入模型、运行 Agent、重做原生权限弹窗及 Provider 生命周期，也没有做完整屏幕阅读器语音检查。pi/Claude 的真实目录创建与故障反馈只核对代码和展示面，不能称为原生端到端通过。

未替换用户先前打开的旧应用包；新源码构建与旧运行进程是不同版本。视觉改动不等于用户已认可设计，#20 不自动关闭。未推送或更新线上 Issue。
